# 岩石與礦物大富翁・豪華教學版

這是一個可直接部署到 **GitHub Pages** 的靜態網頁遊戲，主題為 **岩石與礦物大富翁**，適合國小高年級自然課、班級活動、社團或闖關教學使用。

## 特色

- 更像真正大富翁的棋盤式玩法
- 2～4 人輪流遊玩
- 岩石與礦物主題地產購買與過路費機制
- 國小高年級教學版題庫
- 音效與動畫粒子效果
- 本機排行榜（localStorage）
- 單一 `index.html` 即可部署

## 如何部署到 GitHub Pages

1. 建立新的 GitHub Repository
2. 上傳 `index.html`
3. 進入 `Settings`
4. 點選 `Pages`
5. 在 **Build and deployment** 中選擇：
   - Source：`Deploy from a branch`
   - Branch：`main`
   - Folder：`/root`
6. 儲存後等待幾分鐘
7. GitHub 會提供網站網址

## 建議用途

- 國小自然課岩石與礦物單元複習
- 班級闖關競賽
- 教師研習示範互動教材
- 社團活動暖身遊戲
